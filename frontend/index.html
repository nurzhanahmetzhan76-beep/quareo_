Вопросы

Начать работу легко.

Если не нашли ответ, напишите нам — поможем выбрать удобный сценарий работы.

Можно ли начать без оплаты?
Да. Бесплатный тариф доступен без ограничения по времени и позволяет проверить основные сценарии работы Quareo.
Quareo работает только с Kaspi?
Сейчас основной рабочий контур рассчитан на Kaspi. Архитектура продукта развивается для подключения других маркетплейсов.
Нужны ли специальные навыки?
Нет. Quareo показывает задачу и рекомендуемое действие простым языком, поэтому начать можно без обучения.
Можно ли сменить тариф позже?
Да, вы сможете выбрать подходящий тариф по мере роста ассортимента и количества операций.
